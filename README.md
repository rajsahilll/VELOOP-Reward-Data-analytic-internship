# VELOOP Rewards – Data Analyst Internship

Product analytics and data management blueprint for VELOOP, a developing rewards app with no production data yet.

> All data is simulated. Nothing here describes real VELOOP users, earnings or performance. Designs are Proposed until engineering verifies them.

## Contents
- docs/ – 10 Word reports: executive summary, product audit, specifications, logical data model, data-quality audit, dashboard blueprint, developer handoff, pipeline, governance, final report
- workbooks/ – 3 Excel files: design workbook, profiling and quality log, supplementary simulated data
- diagrams/ – ER diagram

## Highlights
58 events, 115 data fields, 43 KPIs, 7 dashboards, 15 quality rules, 35 data issues found, 18 open assumptions.
